# UI design

## Verifying

Check the design against the spec and the design system, prototype the interaction, or measure contrast and sizes.

## Severity examples

- **Low**: spacing or alignment slightly off the grid
- **Medium**: a rarely seen state is missing or inconsistent
- **High**: a common task is confusing or blocked for some users
- **Critical**: a core flow can't be completed, or the design is inaccessible to a group of users

## Micro checks

- All states: empty, loading, error, disabled, long content
- Spacing, alignment, and sizes against the design tokens
- Contrast, touch target sizes, and focus states
- Copy: typos, tone, truncation
- Reusing existing components instead of new ones

## Macro checks

- Consistency of flows and patterns across screens
- Navigation and information architecture
- Fit with the design system, and changes it would need
- Behaviour across screen sizes and platforms
