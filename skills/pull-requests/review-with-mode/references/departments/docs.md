# Docs

## Verifying

Follow the steps as written, run the examples, and check claims against the source they describe.

## Severity examples

- **Low**: typos, formatting, tone
- **Medium**: an unclear sentence or a missing detail that readers can work out
- **High**: wrong steps or examples that fail
- **Critical**: instructions likely to cause irreversible data loss, severe security exposure, or broad operational harm

## Micro checks

- Accuracy of each claim, command, and example
- Typos, grammar, and consistent terminology
- Links and cross-references
- Each step makes sense on its own

## Macro checks

- Structure and order: can a reader find and follow it?
- Audience: right level of detail for who reads it
- Duplication or contradiction with other docs
- Gaps: what a reader needs that isn't covered
